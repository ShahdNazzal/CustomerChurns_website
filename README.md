## 🎯 About

This site is the front-end presentation layer for a customer churn analytics project built on the [IBM Telco Customer Churn dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn). It walks visitors through the project's purpose, methodology, and findings, then lets them explore the results directly through a fully interactive, embedded dashboard.

---

## ✨ Features

- **Hero section** — project introduction and tagline
- **Overview cards** — purpose, data source, key questions, and what's inside
- **KPI stats strip** — churn rate, customer count, avg. monthly charges, avg. tenure
- **Live embedded dashboard** — interactive report the visitor can filter and explore directly on the page
- **Methodology timeline** — the 4-step analytical process (cleaning → segmentation → prediction → dashboard)
- **Tech stack showcase**
- Smooth scroll-reveal animations, fully responsive layout

---

## 🛠️ Built With

- **Next.js** (React)
- **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**

---

## 📊 The Dashboard

The embedded dashboard shows:
- Churn rate broken down by contract type, internet service, and payment method
- Customer segments (K-Means clustering)
- Predicted churn probability per customer
- Geographic and tenure-based churn patterns

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/ShahdNazzal/CustomerChurns_website.git
cd CustomerChurns_website

# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.
